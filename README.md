# 天狼 · CHEONRANG

현대 황제국 천람의 황실 직속 특임대 천랑을 소개하는 반응형 정적 웹사이트.

## 구성

- 티저 영상 랜딩과 메인 진입, 영상 재생/음소거 제어
- 운경과 경운궁 전경, 천랑 다섯 인물의 사진·능력 문장·코드네임
- 인물 클릭 시 프로필 모달: X, 바깥 클릭, Esc로 닫기
- 균열·흉수·각성 등급의 서로 다른 문양과 단계별 설명
- 황실, 천무, 가문, 지역, 국가 상징, 기념일과 의례

## 영상 추가

저장소 최상위에 정확히 `CHEONRANG_MAIN_TEASER.MP4` 파일을 추가한다. 대소문자를 구별한다. GitHub의 단일 파일 제한에 걸리는 큰 영상은 별도 호스팅 후 `index.html`의 video source를 변경한다.

영상이 없는 동안에도 천람 전경 포스터와 메인 진입 버튼은 정상 동작한다. 자동 재생은 브라우저 정책에 따라 무음으로 시작하고, 방문자가 소리 켜기를 누르면 음소거가 해제된다.

## 인물 변경

`data.js`의 `members` 배열을 수정한다. 이름별 `id`가 사진 및 문장 파일명과 연결되므로 배열 순서에 의존하지 않는다. 현재 데스크톱은 이겸 · 윤라온 · 현륜 · 소운결 · 한기준, 모바일은 대장 현륜을 먼저 배치한다. 비밀 설정은 공개 사이트에 포함하지 않는다.

## 이미지

`assets/*-emblem.png`는 투명 배경의 인물별 PNG 문장이다. 인물 초상과 기존 천랑 로고는 제공된 자료를 사용했으며, 천람 전경은 이 페이지용으로 제작한 이미지다.

## 배포

GitHub Pages의 **Settings → Pages → Source**를 **GitHub Actions**로 선택한다. `main`에 커밋하면 `.github/workflows/pages.yml`이 테스트 후 정적 사이트를 배포한다. Pages 예상 주소는 `https://myaong-mood.github.io/CHEONRANG/`이다.

별도 빌드나 외부 JavaScript 라이브러리가 필요하지 않다. UTF-8로 저장하고 하위 경로에서도 동작하도록 상대 경로를 사용한다.
